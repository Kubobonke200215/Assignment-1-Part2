# Changelog

All notable changes to the **Siyakhana Legal Advice Centre** website are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

---

## [1.1.0] – 2026-09-17

### Added
- Complete set of organisation images (logo, homepage illustrations, service images)
- Proper image references across all pages
- Clean project structure with dedicated `Images/` folder

### Fixed
- Broken image paths that prevented images from displaying
- Missing image files in the final project package

---

## [1.0.0] – 2026-09-17

### Added
- Clean, fully functional multi-page website
- Responsive design (mobile, tablet, and desktop)
- Consistent header and navigation on every page
- Professional footer with contact details and social media icons
- Fixed “Chat with Siyakhana Legal” button
- Google Maps embed on the Contact page
- Enquiry form with personal details and consultation booking options
- Contact form with location and enquiry type selectors
- Single consolidated CSS file using CSS variables
- Project README documentation

### Changed
- Completely rebuilt all HTML pages from the original messy code
- Reorganised and cleaned the entire CSS (removed duplicated and conflicting styles)
- Standardised colour scheme, typography, and spacing across the site
- Improved accessibility (ARIA labels, proper heading structure, focus states)

### Fixed
- Multiple nested and duplicated `<!DOCTYPE html>`, `<html>`, and `<body>` tags
- Broken and incomplete header brand links
- Incorrect and inconsistent relative file paths
- Overlapping and conflicting CSS rules
- Missing closing tags and structural errors
- Non-functional layout on smaller screens

### Removed
- All duplicated footer code that was pasted into every page
- Unused and conflicting style blocks
- Placeholder / broken social media links structure (cleaned and standardised)
